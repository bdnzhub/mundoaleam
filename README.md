# MundoAleam
Protótipo independente e ficcional de simulador parlamentar do Amazonas. Sem dependências, sem API paga, sem servidor. Abra index.html ou publique como site estático no GitHub Pages.

## Publicação
1. Crie um novo repositório chamado `mundoaleam`, sem alterar os existentes.
2. Envie index.html e README.md à raiz da branch main.
3. Em Settings > Pages > Build and deployment, selecione Deploy from a branch, main, / (root).
4. Aguarde o GitHub informar a URL publicada.

## Limites
Versão 0.1: personagens e dados fictícios, regras simplificadas, orçamento abstrato, não oficial, sem IA remota, mapa geográfico, multiplayer, servidor ou login. Comandos livres classificam ações por palavras-chave e levam ao módulo para confirmação. A carreira de governador termina em epílogo. Não é uma implementação integral das normas da Aleam. Não foram realizados testes reais no Safari.
